# Simple Calculator

A command-line calculator built in Python that performs basic arithmetic operations, including addition, subtraction, multiplication, and division. The application is designed with a clean and interactive interface, demonstrating fundamental Python programming concepts such as functions, loops, conditional statements, and exception handling.

---

# Overview

The **Simple Calculator** is a beginner-friendly Python project that enables users to perform common mathematical operations through an interactive command-line interface. Users can select an operation, enter two numbers, and instantly view the result.

The project focuses on writing clean, modular, and maintainable code while providing a smooth user experience through input validation and error handling.

---

# Features

- Addition
- Subtraction
- Multiplication
- Division
- Input validation for numeric values
- Division-by-zero error handling
- Perform multiple calculations without restarting the program
- Menu-driven interface
- Modular implementation using functions

---

# Getting Started

## Prerequisites

- Python 3.x installed on your system

Verify your Python installation:

```bash
python --version
```

---

## Installation

Clone the repository:

```bash
git clone https://github.com/your-username/Simple-Calculator.git
```

Navigate to the project directory:

```bash
cd Simple-Calculator
```

Run the application:

```bash
python simple_calculator.py
```

---

# How to Use

1. Launch the application.
2. Select one of the available arithmetic operations.
3. Enter the two numbers.
4. View the calculated result.
5. Repeat the process or exit the application.
